Scalable Tournament Bracket Predictor and Simulator

How to Run the Code

To run this code, you simply need to build and run the main.cpp file to launch the command line interface. 

To run in CLion:
1. Clone the Repository and open the P2_DSA folder in CLion.
2. Open main.cpp
3. Click the run button
4. Interact with the simulator directly in the CLion terminal.

Features
1. Set weights for different strength attributes. 
2. Search for a specific competitor by ID
3. Build and Simulate a Bracket
4. Run a benchmark to compare tree performances.
